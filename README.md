# Odoo 19 Student Management System

A custom Student Management System developed using Odoo 19, Python, PostgreSQL, XML, and QWeb.

## Features

- Student Management
- Department Management
- Teacher Management
- Subject Management
- Semester Management
- Fee Structure
- Student Semester Fees
- Student Marks and Grades
- Teacher Leave Management
- Email Wizard
- Bulk Update Wizard
- Assign Department Wizard
- PDF Reports
- Role-Based Access Rights
- Sales Module Customization
- Product Category / Make Filtering
- Custom Sales Quotation PDF

## Technologies Used

- Odoo 19
- Python
- PostgreSQL
- XML
- QWeb
- Git
- GitHub
- Ubuntu Linux
